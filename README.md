# 🦖 DigiStory — Explorando o Universo Digimon

## 📖 Sobre o projeto

O **DigiStory** é um projeto desenvolvido com HTML, CSS e JavaScript que permite explorar o universo Digimon por meio da integração com a **Digi-API**.

A plataforma apresenta informações sobre diferentes Digimons, permitindo pesquisar personagens, visualizar suas características e descobrir novos registros de maneira interativa.

## 🚀 Funcionalidades

- **Listagem de Digimons:** exibição dos personagens disponíveis na API.
- **Pesquisa por nome:** permite encontrar um Digimon pelo seu nome.
- **Pesquisa por ID:** permite localizar um Digimon utilizando seu identificador.
- **Informações detalhadas:** apresenta dados como nome, imagem, tipo, nível, atributo, campos, descrição e habilidades.
- **Navegação:** permite avançar para o próximo Digimon e retornar ao anterior.
- **Me surpreenda:** seleciona um Digimon aleatório.
- **Paginação:** organiza a listagem dos personagens em páginas.
- **Tema claro e escuro:** oferece diferentes opções de visualização.

## 🛠️ Tecnologias utilizadas

- HTML5 — estrutura das páginas.
- CSS3 — estilização e organização visual.
- JavaScript — funcionalidades e integração com a API.
- Digi-API — fornecimento dos dados dos Digimons.

## 🌐 API utilizada

O projeto utiliza a Digi-API para consultar e apresentar informações dos personagens.

🔗 https://digi-api.com/

## ▶️ Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Execute o arquivo `index.html` utilizando a extensão Live Server.
4. Certifique-se de estar conectado à internet para acessar a Digi-API.
5. Explore as funcionalidades do DigiStory!
